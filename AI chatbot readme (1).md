# Rule-Based AI Chatbot

## 📌 Description
This is a simple **Rule-Based AI Chatbot** built in Python as part of **Project 1**. The chatbot uses basic `if-else` logic to match predefined user inputs and generate appropriate responses. It runs in a continuous loop inside the terminal, allowing the user to have a back-and-forth conversation until they choose to exit.

The chatbot can:
- Greet the user (`hi`, `hello`, `hey`, `salam`, etc.)
- Respond to casual questions like *"how are you"*
- Tell its name and purpose when asked
- Explain what it can do (`help`)
- Respond to thanks (`thank you`, `shukriya`)
- End the conversation on exit commands (`bye`, `exit`, `quit`, `goodbye`, `khuda hafiz`)

## 🛠️ Technologies Used
- Python 3

## ▶️ How to Run
1. Make sure Python is installed on your system. Check by running:
   ```
   python --version
   ```
2. Open the project folder in your terminal (or VS Code integrated terminal).
3. Navigate to the folder containing `chatbot.py`:
   ```
   cd path\to\your\folder
   ```
4. Run the chatbot using:
   ```
   python chatbot.py
   ```

## 💬 How to Use
Once the chatbot starts, you'll see:
```
=== Rule-Based AI Chatbot ===
Type 'bye', 'exit', or 'quit' to end the chat.
```

Simply type your message after `You:` and press Enter. Example conversation:
```
You: Hi
Bot: Hello! How can I help you today?
You: What's Your name?
Bot: My name is ChatBuddy!
You: How are you?
Bot: I'm just a bot, but I'm doing great! How about you?
You: bye
Bot: Goodbye! Have a great day. 👋
```

To end the chat at any time, type `bye`, `exit`, `quit`, `goodbye`, or `khuda hafiz`.
